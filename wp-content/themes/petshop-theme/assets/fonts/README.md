# Fontes da composição de login

Nunito Sans (variável, pesos 400–800) e Kalam (700), subconjunto Latin em WOFF2.
Fontes locais, aplicadas somente à composição de entrada e ao seu canvas no editor.
As licenças SIL Open Font License estão preservadas nesta pasta.

Origem: Google Fonts, obtidas em 2026-10-11 pelo CSS oficial de
`fonts.googleapis.com` e pelos binários indicados em `fonts.gstatic.com`.
Licenças originais:

- https://github.com/google/fonts/tree/main/ofl/nunitosans
- https://github.com/google/fonts/tree/main/ofl/kalam

As famílias CSS têm nomes próprios para não mudar a tipografia global do tema.
