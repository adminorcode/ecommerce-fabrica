# Edição do rodapé institucional

O rodapé escuro da loja é conteúdo **global**. Edite pelo Customizer e pelos menus — não pela Home no Gutenberg.

## Onde editar

| Bloco | Origem |
| --- | --- |
| Logo | **Aparência → Personalizar → Identidade do site** |
| Descrição / tagline | **Personalizar → Rodapé da loja** |
| Instagram, Facebook, TikTok, WhatsApp (redes, abaixo de “Siga-nos”) | **Personalizar → Rodapé da loja** |
| WhatsApp de atendimento, e-mail, horário, FAQ, texto auxiliar do atendimento | **Personalizar → Rodapé da loja** |
| Página usada pelo link “Atendimento ao cliente” | **Personalizar → Conteúdo da loja → Página de atendimento do cabeçalho** |
| Categorias | **Aparência → Menus** → localização `petshop-primary` |
| Institucional | **Aparência → Menus** → localização `petshop-footer` |
| Selos de confiança (até 4) | **Personalizar → Rodapé da loja** (título + descrição; vazio = oculto). Os ícones seguem a ordem: compra segura, qualidade, ambiente protegido, envio. |
| Copyright, razão social, CNPJ, endereço | **Personalizar → Rodapé da loja** |
| Formas de pagamento (texto) | **Personalizar → Rodapé da loja** (aparece na faixa legal, sem coluna extra) |

## Regras

- Campo/URL vazio: o item correspondente some do rodapé.
- WhatsApp de **atendimento** e WhatsApp das **redes** são campos distintos.
- Redes e selos usam ícones SVG do tema (não há upload de ícone por rede).
- Horário aceita várias linhas (uma por período).
- Minha conta e Meus pedidos ficam no cabeçalho, não no menu institucional.
